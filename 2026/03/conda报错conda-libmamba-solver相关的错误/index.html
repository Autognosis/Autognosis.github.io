conda报错：conda-libmamba-solver相关的错误

Contents

  1. 问题描述
  2. 解决方案

问题描述

报错信息：

1Error while loading conda entry point: conda-libmamba-solver (cannot import name 'Spinner' from 'conda.common.io' (D:\ProgramData\mambaforge\lib\site-packages\conda\common\io.py))

这其实是 libmamba-solver 和 conda 的版本不兼容导致的。

我的情况是使用 mamba 安装的 conda，但是不知道为什么，mamba 直接报错了。执行 mamba -v 时，直接命令失败。由于 conda 默认的 solver 被设置为了 libmamba-solver，导使用 conda 更新也失败了。

解决方案

使用 classic solver 更新所有包：

1conda update --all --solver classic
